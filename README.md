# Grand Pilatus App

## Architektur
- Frontend: React + TypeScript (SPA)
- Backend: Node.js + Express + TypeScript
- Datenbank: MongoDB Atlas
- API-Format: REST + JSON
- API-Spezifikation: `docs/api.yaml`
